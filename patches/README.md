# IPS patches

QuarrelEx does not include Battle City ROM images. Each maintained ROM line keeps one current release patch.

## BCEX 16KB

```text
16KB/QuarrelEx_BCEX_16KB_v1.0.ips
```

Required input:

```text
Battle City (J)
Size:    24592 bytes
CRC32:   F599A07E
SHA-256: a869aead5b6957fc62002ff9636e048cc34baf0100d629b07dc51aa18f220c0c
```

Expected output:

```text
Size:    24592 bytes
CRC32:   AECB82CE
SHA-256: 33d51720a9891b6eb4a835b8fd9c4181c3689452456aaa417914e3dbb3427939
```

## BCEX 32KB Final

```text
32KB/QuarrelEx_BCEX_32KB_Final.ips
```

Required input:

```text
Size:    40976 bytes
CRC32:   D2572735
SHA-256: 5e0b53e33a40166e5d31d50734c6059c96bc061301d2b77e85bd10a744e53291
```

Expected output:

```text
Size:    40976 bytes
CRC32:   E33746DA
SHA-256: ab85c29a8ee0dd68078d5fce959147e6400105e1f55fdda975e13ce9c7c05aa8
```

Do not apply a patch to a ROM with a different checksum. Historical incremental patches are intentionally not part of the source repository.
