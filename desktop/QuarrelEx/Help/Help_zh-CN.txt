Quarrel Ex Desktop v0.8 中文帮助
===============================

1. 软件简介
-----------
Quarrel Ex Desktop 是使用 C# WinForms / .NET 8 重建的 Battle City / 坦克大战桌面编辑器。

本版把 Desktop v0.8 已验证的功能同步到桌面端，并保留：
- 原 Quarrel 黄色坦克图标。
- Per-Monitor V2 高 DPI。
- 13×13 地图完整显示。
- 原版 / 16KB Ex / 32KB Ex 安全切换。
- 中文、英文和 TSA 专项帮助。

当前支持：
- Battle City 日版原版 16KB。
- Legacy Battle City Ex 16KB / 32KB Overlay。
- BCEX v2 Phase 3 / Phase 4 / Phase 5。
- 32KB Stage 1~70 独立地图。
- Phase 4+ 每关 1~255 总敌人数。
- Phase 5 16KB 的 00~1F 地形。
- Phase 5 32KB 的 00~3F 共64地形，其中20~3F为自定义槽。
- Attr 0~3 与可视化 CHR Tile TSA 编辑。
- BCEX FeatureFlags / EnemyItemFlags。

2. 打开、保存和切换 ROM
----------------------
打开 ROM：文件 → 打开 ROM，或 Ctrl+O。
保存 ROM：Ctrl+S。
另存为：文件 → 另存为。
也可以把 .nes ROM 直接拖到桌面编辑器窗口打开。若当前 ROM 有未保存修改，会先询问“是 / 否 / 取消”：是=保存/另存为成功后打开；否=不保存直接打开；取消=保持当前 ROM。
Ctrl+Z：撤销。
F1：中文帮助。
Shift+F1：English Help。

切换 ROM 时，桌面版会先解除旧地图、地形按钮、TSA预览与旧 Renderer 的关系，再载入新 ROM，因此可以在原版、16KB Ex、32KB Overlay、32KB 70-map之间反复切换。

3. 原版 Battle City 模式
------------------------
原版模式提供：
- Stage 1~35 + Demo。
- 13×13 地图编辑。
- 原版 00~0F 共16项 TSA / Attribute。
- Stage 1~35 Enemy Type / Count。
- Demo敌人数据与Stage35共用。

Enemy Type 的 bit2（$04）是闪光奖励标志；常用基础值 $80/$A0/$C0/$E0，对应强制闪光值 $84/$A4/$C4/$E4。原版第4、11、18辆出生敌人还会由程序自动加 $04。

原版不会开放Ex FeatureFlags、36~70独立敌人、10~17扩展地形或32KB敌人拾取功能。

4. Battle City Ex 16KB
----------------------
16KB Ex支持：
- Stage 1~70选择。
- Stage 36~70独立 Enemy Type / Count。
- 00~0D原地形与10~17扩展水块的 TSA / Attribute。
- BCEX v2 FeatureFlags（如果ROM包含BCEX v2配置块和运行程序）。

16KB原生地图仍是4-bit格式，因此Stage36~70地图复用Stage1~35，正式关卡也不能直接保存10~17。
当你第一次在正式地图放置10~17时，桌面版会按桌面版相同逻辑自动转换为32KB Legacy Overlay。

16KB BCEX v2 Phase 3可用功能：
- 按住B自动连发。
- 手枪 / Lv4。
- 被击中逐级降低。
- Phase 6.1+ 闪光坦克奖励使用原版式“立即替换当前道具”；Pending 队列已废弃。
- 随机敌坦克出现顺序。
- Lv4消除树林。

敌人拾取道具只支持32KB 70-map格式。

5. 旧32KB Overlay模式
---------------------
Legacy 32KB Overlay继续兼容：
- 10~17使用“原地图0E标记 + Overlay真实ID”。
- Stage36~70地图继续复用Stage1~35。
- Stage36~70 Enemy Type / Count独立。

“工具 -> 转换为32KB Overlay（Legacy）”可以主动把16KB Ex转换为此格式。

6. 新32KB / 70张独立地图
-----------------------
BCEX v2 Phase 3/4的新32KB格式：
- Stage1~70全部独立。
- 每关182 bytes = 13行×14-byte stride。
- 每行前13字节为可编辑地形，第14字节保留原读取步长。
- 地形ID 00~17直接按1 byte保存。
- 不再使用0E Overlay标记。

因此修改Stage36不会改变Stage1，修改Stage70也不会改变Stage35。

7. 地图与地形
-------------
地形按钮左键：选择。
地图左键：放置。
按住左键拖动：连续绘制。
地图右键：吸取。
Ctrl+Z：撤销。

地图固定显示完整13×13，不会因为WinForms桌面程序DPI/缩放而裁掉某一行或某一列。

原版地形：00~0F。
Ex常规地形：00~0D、10~17。
10 右下单格水
11 左下单格水
12 上横双格水
13 下横双格水
14 左上单格水
15 右上单格水
16 左竖双格水
17 右竖双格水

8. 敌人 Type / Count 与自定义总数量
---------------------------------
敌人页有4个槽：
- Type：十六进制。
- Count：十进制，每个槽可为 0~255。

常见类型：
80 普通
A0 快速
C0 火力
E0 装甲

在支持“Custom Enemy Total”的 BCEX v2 Phase 4 ROM 中：
- 四个 Count 的合计就是本关实际敌人总数。
- 合计必须在 1~255。
- 例如 40 + 30 + 20 + 10 = 100，本关就会实际生成100辆。
- 某一种敌人可以设为0。
- 编辑器会阻止四项合计超过255或变成0。

旧版/原版 ROM 没有这段运行程序，因此仍应保持合计20；桌面版会明确提示当前ROM是否支持1~255。

当总数超过20时，游戏右侧原版的20个敌人图标不会扩展成255个图标：在剩余数量高于20时保持20个图标，进入最后20辆以后才逐个消去。

Ex的Stage1~35使用原表；Stage36~70使用独立Ex表。
原版Demo与Stage35共用敌人数据。

9. BCEX v2 Ex选项
-----------------
只有检测到BCEX v2配置头时才能编辑功能开关。桌面版只修改配置字节，不通过NOP/JMP改写程序本体。

FeatureFlags（CPU $EF7A）：
bit0 $01 按住B自动连发
bit1 $02 手枪 + Lv4
bit2 $04 被击中逐级降低
bit3 $08 我方坦克加速移动（Phase 6.2；旧版 ROM 不开放此位）
bit4 $10 随机敌坦克出现顺序
bit5 $20 Lv4子弹消除树林
bit6 $40 敌人可以拾取道具（32KB 70-map专用）

“原版行为”预设 = $00。
“推荐Ex”预设 = $A7：B连发、手枪/Lv4、逐级掉级、道具排队修复、Lv4消树开启；随机敌人和敌人拾取关闭。

随机敌人只随机出现顺序。程序只从剩余数量非0的类型中选择，所以最终20辆组成仍符合Count表。

10. 32KB敌人拾取道具
--------------------
仅BCEX v2 32KB / 70独立地图开放。

总开关：FeatureFlags bit6。
EnemyItemFlags（CPU $EF7B）：
bit0 头盔
bit1 时钟
bit2 铲子
bit3 星星
bit4 手雷
bit5 坦克
bit6 手枪

当前行为以Battle City Y.S（烟山坦克）H以后机制为参考。敌人总开关关闭时，各个效果复选框也会禁用。

11. 手枪 / Lv4规则
------------------
启用后：
星星：Lv0 -> Lv1 -> Lv2 -> Lv3 -> Lv4，Lv4封顶。
手枪：Lv0/Lv1/Lv2 -> Lv3；Lv3保持；Lv4保持。

逐级掉级开启时：
Lv4 -> Lv3 -> Lv2 -> Lv1 -> Lv0 -> 下一次受击才爆炸。

Lv4消树开启时，只有真正Lv4的玩家子弹可以逐个8×8 Tile消除树林。

12. TSA / Attribute 与 CHR Tile 选择
-----------------------------------
原版 ROM 的表仍有 00~0F，但编辑器屏蔽内部 0E、0F，只显示 00~0D。
Ex 同样屏蔽 0E、0F；根据版本显示 00~0D + 10~17 / 10~1F / 10~3F。

ID 是16×16复合地形编号。

Attr 不再手输十六进制，而是直接从 0、1、2、3 中选择。
它表示该16×16地形使用的背景调色板组；NES背景Attribute只有2 bit，因此这里有效值就是0~3。

TL / TR / BL / BR 分别表示16×16地形中的左上、右上、左下、右下四个8×8背景 CHR Tile。
v0.8 不再要求手工输入 Tile 十六进制：
1) 点击 TL/TR/BL/BR 的小图预览；
2) 打开256个背景CHR Tile的可视化选择器；
3) 直接点击想使用的 Tile；
4) 地形预览和地图立即刷新。

CHR选择窗口按照该地形当前Attr的调色板显示，因此可以同时看到“图案+实际配色”。

如果不理解这些字段，请使用“帮助 -> TSA / 属性说明（中文）”或TSA页顶部的“? 中文 TSA 说明”。

12. Phase 5：单格砖/钢与扩展地形
------------------------------
新增地形：
- 18 左上单格砖：0F 00 / 00 00
- 19 右上单格砖：00 0F / 00 00
- 1A 左下单格砖：00 00 / 0F 00
- 1B 右下单格砖：00 00 / 00 0F
- 1C 左上单格钢：10 00 / 00 00
- 1D 右上单格钢：00 10 / 00 00
- 1E 左下单格钢：00 00 / 10 00
- 1F 右下单格钢：00 00 / 00 10

16KB Phase 5 的地形定义表支持 00~1F，但原关卡仍为4-bit压缩格式；正式地图使用10~1F时，桌面版会转换为32KB Legacy Overlay保存真实ID。

32KB Phase 5 / 70-map直接支持一字节地形ID，并将TSA/Attr扩到00~3F共64项。
20~3F默认全部为 Attr=0、TSA=00 00 00 00，作为后续自定义地形槽。可在TSA页用CHR Tile选择器自行定义，然后直接用于70张地图。

“取消队友互伤”使用FeatureFlags bit7。开启后玩家子弹不再使另一位玩家进入原版的硬直/暂停状态；敌人子弹打玩家的流程不受影响。

13. WinForms桌面程序版注意事项
--------------------
- 所有ROM处理都在本机WinForms桌面程序内完成，不会上传ROM。
- 建议保留ROM备份。
- 某些WinForms桌面程序在file://环境不允许直接覆盖原文件，此时“保存”会自动退化为下载文件。
- 未识别的Mapper或未知Battle City布局会拒绝打开，以避免写错地址。


14. v0.9 / Phase 6 新功能
-------------------------
- 红色奖励坦克：当已有道具时，新的奖励不会丢失，而是进入等待队列；当前道具被吃掉后下一件立即释放。原引擎只有一个活动道具显示槽，因此当前实现是顺序出现，而不是同时显示多个。
- 逐级降级时会触发普通“子弹命中坦克”的音效。
- 锁定初始状态：Phase 6 才可开启。它不影响这一条命中继续吃星星/手枪升级；真正死亡后，下一次出生恢复“游戏设置”中的初始等级。

15. 调色板编辑器
------------------
恢复原 Quarrel 的 Palette Editor。提供 Sprite、Frame2、Level、Frame1、Title、Level Select、Misc1、Misc2 八组，每组16个 NES 色号。点击色块从64色 NES Palette 中选择。修改 Level Palette 会同步影响地图、TSA和CHR预览。

16. Flag TSA Editor
-------------------
恢复 Flag / Fort TSA 编辑。两组都是 6×4 个背景 CHR Tile；ROM 中每行第7字节的 FF 结束标记由编辑器自动保留。点击格子用 CHR Tile Picker 选择。

17. 通用配置文件
----------------
文件 -> 导出配置 / 导入配置。推荐扩展名 `.qexcfg.json`。桌面与 Web 使用完全相同的 `QuarrelExConfig` v3 JSON，；正式版只接受 v3。
配置包含：命数、初始等级、锁定选项、FeatureFlags、EnemyItemFlags、出生位置、8组调色板、可编辑TSA、Flag/Fort TSA，以及完整关卡数据。

Config v3 的 Stages：
- Ex：Stage 1~70；原版：Stage 1~35。
- 每关 13×13 地图（Map）。
- 每关四个 EnemyTypes 原始字节。
- 每关四个 EnemyCounts。
- 每关 EnemyTotal（为四个 Count 合计，用于可读性和完整性检查）。

Enemy Type 说明：常用基础值为 $80/$A0/$C0/$E0。运行时 bit2（$04）是闪光/奖励标志，因此 $84/$A4/$C4/$E4 可表示强制闪光。原版流程还会自动给第4、11、18辆出生敌人加 $04。

导入到没有70独立地图的 Ex 时，Stage36~70 地图不会覆盖 Stage1~35；36~70 的 Enemy Type/Count 仍会导入。导入到不支持1~255总敌人数的 ROM 时，合计不为20的 Count 会跳过并提示。

18. 游戏设置
-------------
- 起始命数 1~255。
- 初始坦克等级：原版 Lv0~Lv3；Ex Lv0~Lv4。
- Phase6 锁定初始状态。
- 三个敌人出生点和 P1/P2 出生点，X/Y 0~255。
- 清空当前关卡 / 清空全部关卡，统一写成地形 0D。


【Phase 6.1 闪光坦克奖励修复】
每次击中闪光坦克都立即调用新的道具生成。若已有道具，旧道具立刻消失并替换成新随机道具。Phase 5/6 的 Pending 队列逻辑已废弃。


15. v0.9.2 低分辨率显示修复

针对 1366×768 / 1280×720 以及 Windows 125%/150% 缩放重新调整主界面比例。TSA / 属性现在使用独立的双向滚动视口；当 TL/TR/BL/BR 横向放不下时，请使用 TSA 区域底部横向滚动条，不会再把列压缩成一个像素。调色板 4×4 色块和 NES 64 色选择器也缩小。


16. v0.9.3 独立工具窗口
-------------------------
桌面版恢复类似原 Quarrel 的工作方式：主窗口只保留 13×13 地图与地形块列表，原来右侧的编辑页全部改为可独立移动/缩放的工具窗口。

快捷键：
F2  敌人编辑器
F3  TSA / 属性编辑器
F4  调色板编辑器
F5  Flag TSA Editor
F6  游戏设置
F7  Ex 选项
F8  ROM 信息

也可以使用“窗口(W)”菜单，或工具栏上的小图标打开。关闭工具窗口只会隐藏，不会清空当前编辑状态；再次打开会回到原窗口。

“窗口 -> 显示全部工具窗口 / 隐藏全部工具窗口”可以一次管理所有工具窗口。每个工具窗口都沿用原 Quarrel 主程序图标。

在 720p/768p 屏幕上，建议主窗口只放地图和地形；需要 TSA/调色板时单独打开对应窗口，这样不会再让右半区挤压主地图。


【v0.9.4 / Phase 6.2】
- 修复调色板4×4表格最后一列被窗口宽度拉伸的问题；色块保持固定紧凑尺寸。
- 游戏设置新增出生位置可视化：P1/P2使用实际玩家坦克CHR并分别使用Sprite Palette 0/1；敌人1~3使用敌坦克CHR。可鼠标拖拽，也可输入X/Y。
- Ex新增“我方坦克加速移动”：需要Phase 6.2运行支持，FeatureFlags bit3。默认关闭。
- 通用配置当前为 QuarrelExConfig v3；正式版只导入/导出 v3，不再保留 v1/v2 兼容分支。


【v1.0 正式版文件操作】
- 配置：只导入/导出 QuarrelExConfig v3（*.qexcfg.json）。
- 导出配置完成后会弹出“配置导出成功”提示。
- 导入配置会先完整检查；有硬错误时不会修改当前 ROM。
- 兼容性差异（例如目标 ROM 不支持70独立地图或255敌人）会作为警告显示。
- 撤销：Ctrl+Z。
- 重做：Ctrl+Y 或 Ctrl+Shift+Z。
- 保存：Ctrl+S，写回当前 ROM 路径。
- 另存为：Ctrl+Shift+S，成功后新文件成为当前 ROM 路径。

【v1.1 Demo + Screen Editor】
- 原版与所有支持的 Ex ROM 都会在正常关卡列表末尾显示 Demo。Demo 不是 Stage 71；它使用原游戏物理地图槽36。
- Demo 继续使用 13×13 地图编辑器，但底层是原版4-bit地图，所以只允许 $00~$0D；Enemy Type/Count 与 Stage 35 共用。
- F9 打开 Title / Game Over Screen Editor。
- 普通标题字符串按 8×8 CHR Tile 编辑；BATTLE/CITY/GAME/OVER 是原版32×32放大字形，每个大框编辑一个完整源字形。
- Screen Editor 不改坐标、字符串长度或 $FF 终止符。
- Config v3 版本号仍为3；新增 Demo 与 Screens 可选字段，旧v3缺失时保留目标ROM原值。


【v1.1.2 / Runtime 6.5~6.6 Final Rules】
- 游戏设置新增 Stage 1~70 自定义敌人出生点。1P/2P 各选 Original 或 1~8，共用 S1~S8 坐标；支持实际地图预览、拖拽、16px 吸附和 $18~$D8 安全边界。
- Final GAME OVER Skip 默认 OFF。
- 加命规则：Original / Custom Once / Repeat / Disabled，数值单位为 10,000 分。
- 2P Bonus：Original 或 Win Streak。
- 400分装甲坦克：Original 或 One Hit。
- Runtime 6.5 / QXR1 v2 提供上述 Final Rules 和自定义出生点；Runtime 6.6 / QXR1 v3 在此基础上增加：
  · 标题画面按住 A+B 再按 Start 的秘籍命数，1P/2P 独立设置，默认均为 10；普通 Start 不受影响。
  · Stage 1~70 独立的 1P/2P 敌人出现间隔（1~255 帧，越小越快）与最大同时在场敌人数（1~6）。
  · 可一键复制 Stage 35 节奏，也可恢复该关的原版节奏。
- 修改主地图后，“游戏设置”中的原版出生点地图和 S1~S8 自定义出生点地图会立即同步刷新。


【Runtime 6.7 / QXR1 v4】
- 装甲坦克 One Hit：仅普通 400 分装甲坦克变为白色 1HP；闪光/带道具的 400 分装甲坦克保持原版 4 发耐久和奖励逻辑。
- Flag TSA Editor 新增 Stage 1~70 独立“存在老巢”开关。关闭后 Runtime 不绘制普通/铁锹老巢，老巢区域下方地图数据正常生效。
