Quarrel Ex - TSA / 属性ガイド
=============================

TSA は 16×16 の地形ブロックを構成するデータです。
各地形 ID は次の情報を持ちます。

- Attr: 背景パレット番号 0～3
- TL: 左上 8×8 CHR Tile
- TR: 右上 8×8 CHR Tile
- BL: 左下 8×8 CHR Tile
- BR: 右下 8×8 CHR Tile

地形 ID と CHR Tile ID は別のものです。
たとえば地形 $0A が「水」を表していても、実際の 4 つの CHR Tile は別の番号を参照します。

編集方法
--------
1. TSA / 属性エディタで地形 ID を選びます。
2. Attr は 0～3 から選びます。
3. TL/TR/BL/BR をクリックすると CHR Tile Picker が開きます。
4. 256 個の背景 CHR Tile から目的の Tile を選択します。

$0E/$0F は内部予約値なので、通常のマップ/TSA編集では使用しません。
対応する拡張 Runtime では $10～$1F、さらに Terrain64 では $20～$3F のカスタムスロットを利用できます。

注意
----
TSA の変更は見た目だけでなく、地形の衝突・破壊・水・森林・氷などの挙動に影響する場合があります。
編集前に ROM のバックアップを作成してください。
