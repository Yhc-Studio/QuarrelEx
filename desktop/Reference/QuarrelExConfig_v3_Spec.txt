QuarrelExConfig v3 - Formal Shared Configuration
================================================

Required root:
  Schema  = "QuarrelExConfig"
  Version = 3

Formal Desktop v1.1.4 / Web v1.6.4 import only Version 3.
Older v1/v2 configs are intentionally rejected.

Gameplay
--------
StartingLives       integer 1..255
InitialTankLevel    integer 0..4 (original target supports 0..3)
LockInitialState    boolean
PlayerFastMove      boolean/null; when FeatureFlags is present, must agree with bit3
FeatureFlags        integer 0..255 or null
EnemyItemFlags      integer 0..127 or null
Spawns              Enemy1/Enemy2/Enemy3/Player1/Player2, each X/Y integer 0..255

Gameplay.FinalRules (optional v3 extension; QXR1 v2/v3 / Runtime 6.5/6.6)
------------------------------------------------------------------------
SkipFinalGameOver   boolean; default ROM value is OFF
ExtraLifeMode       integer 0..3
                    0 Original / 1 Custom Once / 2 Repeat / 3 Disabled
ExtraLifeValue      integer 1..99, units of 10,000 points
TwoPlayerBonusMode  integer 0..1; 0 Original / 1 Win Streak
ArmoredTankMode     integer 0..1; 0 Original / 1 One Hit
CheatPlayer1Lives   optional integer 1..99; QXR1 v3 / Runtime 6.6, default ROM value 10
CheatPlayer2Lives   optional integer 1..99; QXR1 v3 / Runtime 6.6, default ROM value 10

If this optional object is absent, the target ROM keeps its current Final Rules values.
If the target ROM does not contain QXR1 v2/v3, the object is ignored with a compatibility warning.
CheatPlayer1Lives/CheatPlayer2Lives are ignored with a warning on QXR1 v2 targets.

Palettes
--------
Required groups:
  Sprite, Frame2, Level, Frame1, Title, LevelSelect, Misc1, Misc2
Each group: exactly 16 integers, each 0..63.

Terrain
-------
Array of definitions:
  Id    integer $00..$3F, unique
  Attr  integer 0..3
  Tiles exactly 4 integers 0..255 (TL/TR/BL/BR)
$0E/$0F are internal/reserved; imports warn and skip them.
Definitions outside the target ROM's TerrainCount are compatibility warnings and are skipped.

FlagTsa
-------
Flag: exactly 24 integers 0..255 (6x4)
Fort: exactly 24 integers 0..255 (6x4)

Stages
------
Exactly 35 stages (original-source config) or exactly 70 stages (Ex-source config).
Stage numbers must be unique and continuous from 1.
Each stage contains:
  Map          exactly 13 rows x 13 columns, IDs $00..$3F
  EnemyTypes   exactly 4 integers 0..255
  EnemyCounts  exactly 4 integers 0..255
  EnemyTotal   integer equal to sum(EnemyCounts)
EnemyCounts sum must be 1..255.

Stages[].EnemySpawn (optional v3 extension; Runtime 6.5)
--------------------------------------------------------
Player1Count   integer 0..8; 0 = Original, 1..8 = custom point count
Player2Count   integer 0..8; independent from Player1Count
Points         exactly 8 objects {X,Y}; coordinates are shared by 1P/2P
X/Y            integer $18..$D8

The editor UI can snap coordinates to 16px centers and warns when a point is on terrain other than $0D.
If EnemySpawn is absent, that stage keeps the target ROM's current spawn record.

Stages[].EnemyPacing (optional v3 extension; QXR1 v3 / Runtime 6.6)
-------------------------------------------------------------------
Player1IntervalFrames integer 1..255; lower value = faster enemy appearance
Player2IntervalFrames integer 1..255
Player1MaxActive      integer 1..6; maximum simultaneous enemy tanks in 1P
Player2MaxActive      integer 1..6; maximum simultaneous enemy tanks in 2P

Runtime 6.6 defaults reproduce the original pacing curve for Stage 1..35; Stage 36..70 default to the Stage 35 maximum-speed timing.
Stage 35 reference values are 1P=50 frames and 2P=30 frames; original max-active values are 1P=4 and 2P=6.
EnemyPacing is separate from EnemyCounts: the four EnemyCounts still control the stage's total enemy composition.
If EnemyPacing is absent, that stage keeps the target ROM's current pacing values. QXR1 v2 targets ignore EnemyPacing with a warning.

Demo (optional v3 extension)
----------------------------
Demo.Map: exactly 13 rows x 13 columns.
The Demo map is ROM-native and remains in the original 4-bit map format, therefore writable terrain IDs are $00..$0D. $0E/$0F are reserved and are preserved rather than written.
Older Config v3 files without Demo remain valid; the target ROM keeps its current Demo map.

Screens (optional v3 extension)
-------------------------------
Screens.Title.Elements and Screens.GameOver.Elements store the ROM-native screen string sources.
Known keys have fixed lengths and every value must be integer $00..$FE; $FF is reserved as the original string terminator and cannot be written into an element.

Title native elements:
  Title.Battle       6  (32x32 magnified glyph source)
  Title.City         4  (32x32 magnified glyph source)
  Title.TopLeft      2  (8x8 tile string)
  Title.TopCenter    3  (8x8 tile string)
  Title.TopRight     2  (8x8 tile string)
  Title.OnePlayer    8  (8x8 tile string)
  Title.TwoPlayers   9  (8x8 tile string)
  Title.Construction 12 (8x8 tile string)
  Title.SymbolRow    9  (8x8 tile string)
  Title.Copyright    22 (8x8 tile string)
  Title.Rights       19 (8x8 tile string)

Game Over native elements:
  GameOver.Game      4  (32x32 magnified glyph source)
  GameOver.Over      4  (32x32 magnified glyph source)

Older Config v3 files without Screens remain valid; the target ROM keeps its current Title/Game Over data.

Hard errors vs compatibility warnings
-------------------------------------
Hard error examples:
- wrong/missing Schema or Version
- malformed JSON/type mismatch
- missing required palette/spawn/stage data
- wrong array lengths
- out-of-range values
- duplicate/missing stages
- EnemyTotal mismatch
- invalid 13x13 map dimensions

On hard error the config is NOT applied at all.

Compatibility warning examples:
- Lv4 config imported to original ROM
- target ROM lacks a requested Ex / Final Rules capability
- target ROM only supports 20 enemies but a stage total is not 20
- Stage36~70 independent maps imported to a shared-map target
- terrain IDs not representable by the target ROM

Warnings may skip or downgrade only the unsupported fields while importing the rest.


### Runtime 6.7 / QXR1 v4

- Armored Tank One Hit now converts only normal 400-point armored tanks to the white 1-HP form; flashing/item armored tanks keep the original multi-hit durability and flashing/item behavior.
- Stage 1-70 now has optional `BaseExists` (Config v3 extension). When false, the runtime skips default/protected HQ drawing so map terrain underneath the HQ area remains active.
- Config schema remains Version 3; older v3 files remain compatible.

Stages[].BaseExists (optional boolean; QXR1 v4 / Runtime 6.7)
  true  = draw/use the original HQ for this stage
  false = do not draw/protect the HQ; underlying map terrain remains active
