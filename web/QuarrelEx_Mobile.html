槽Type (Hex)Count

常用基础 Type：80 普通，A0 快速，C0 火力，E0 装甲。
Type 的 bit2（$04）是闪光/奖励标志，因此 84/A4/C4/E4 可强制闪光；原版流程还会自动给第4、11、18辆出生敌人加 $04。

Battle City Ex v2 功能开关

打开 ROM 后显示功能状态。
游戏功能
敌人拾取后的效果（32KB）
Final Rules（QXR1 v2~v5 · Runtime 6.5~6.9）
需要更新后的 32KB Runtime 6.5~6.9 ROM。
Win Streak 固定规则：1胜=1000，2胜=2000，3胜=4000，4胜=6000，5胜=8000，6胜=10000，7胜及以上=+1命。平局中断连续胜场；胜者改变时从1胜重新计算。
Runtime 6.6：标题画面按住 A+B 再按 Start 启动秘籍命数；默认 1P/2P 均为 10。普通 Start 仍使用“游戏设置”的普通起始命数。
功能开关只修改 BCEX v2 配置字节，不通过 NOP/JMP 改写程序代码。

Title + Game Over Screen Editor

点击蓝框选择图块

1 格 = 1 个 NES 8×8 背景 CHR Tile。BATTLE / CITY / GAME / OVER 在原游戏中由 32×32 放大字形程序绘制，因此每个大蓝框是一个完整的源字形槽，而不是四个可独立修改的 8×8 格。编辑器只改原 ROM 已有字符串内容，不改变坐标、长度或 $FF 终止符；预览 Attr 只影响显示颜色，不写入 ROM。

当前 ROM 有未保存修改

打开新的 ROM 前是否保存当前修改？选择“保存”时会执行保存/另存为，成功后再打开新 ROM；选择“不保存”会直接打开新 ROM。
