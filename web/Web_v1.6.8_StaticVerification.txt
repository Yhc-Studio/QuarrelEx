QuarrelEx Web v1.6.8 static verification
========================================

- QuarrelEx.html and QuarrelEx_Standalone.html are byte-identical.
- Both desktop-oriented Web entries contain 4 inline JavaScript blocks; all pass Node.js v22 --check.
- Shared localization catalogs contain 804 keys each for zh-CN / en-US / ja-JP.
- Direct localization key references are validated by tools/check_i18n.py.
- i18n bootstrap smoke test passes for English / Japanese / Chinese key switching.
- Repeated template placeholders are compiled with one capture plus back-references, so templates such as {0}{1}{0}{0} no longer abort i18n initialization.
- Dynamic map/terrain UI is rebuilt on quarrelex:languagechange; map selection and terrain labels no longer fall back to raw keys / generic Terrain text when i18n is active.
- Reverse binding recognizes unique strings from all three locale catalogs, allowing controls created after a language switch to switch again immediately.
- Browser language is used on first launch; manual language selection is stored in localStorage with a safe fallback when storage is unavailable.
- QuarrelExConfig v3 and QuarrelExStage v1 remain language-neutral and unchanged.
- Existing Runtime 6.9.3 / QXR1 v5 editing support remains present.
- No ROM image or emulator save file is included in the repository.
