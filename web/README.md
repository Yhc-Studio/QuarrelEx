# QuarrelEx Web

Current release:

- Web 1.6.14
- Mobile Web 1.1.1
- BCEX 32KB Final Runtime

Files:

- `QuarrelEx.html` — desktop-oriented self-contained Web editor.
- `QuarrelEx_Mobile.html` — touch-first Mobile Web editor using the same ROM/config model.

Both editors are self-contained, work offline, and process ROM data locally in the browser.
