QuarrelEx Web v1.6.0 Static / Functional Verification
=====================================================

Scope
-----
- Demo map editing
- Unified Title + Game Over Screen Editor
- QuarrelExConfig v3 optional Demo / Screens extensions

JavaScript syntax
-----------------
- QuarrelEx.html contains 3 JavaScript blocks; all pass Node.js `node --check`.
- QuarrelEx_Standalone.html contains 3 JavaScript blocks; all pass Node.js `node --check`.
- The standard and standalone HTML builds are byte-identical in this package.

ROM functional checks
---------------------
Tested with the editor core against:
1. Battle City (J) original 16KB
2. BCEX 16KB Runtime 6.3
3. BCEX 32KB 70-map Runtime 6.4.1

All three passed:
- correct ROM kind detection;
- Demo exposed after the normal stage list (logical 36 in Original, logical 71 in Ex UI model, labelled `Demo`);
- Demo maps to physical original map slot 36;
- a Demo map edit changes only the expected native map byte;
- Demo Enemy Type/Count resolves to Stage 35 data;
- Title screen reports 11 native editable elements;
- Game Over reports 2 native editable elements;
- BATTLE source bytes are 42 41 54 54 4C 45;
- Title.Copyright length is 22 and its final source tile is 69 before FF;
- each native screen element is followed by the expected FF terminator;
- fixed-length screen tile edit changes only the selected ROM source byte;
- writing FF as a screen tile is rejected;
- exported Config v3 contains Demo and Screens and passes preflight validation;
- export -> import round trip is byte-for-byte identical on all three test ROMs;
- older Config v3 files without Demo/Screens remain valid with warnings and preserve those ROM regions.

Native offsets
--------------
16KB Demo map: $3CFB (physical map slot 36)
32KB fixed-main-bank Demo map: $7CFB

Screen source offsets are documented in docs/Screen_Editor.md.
For 32KB ROMs, screen source offsets are shifted by $4000.

Runtime
-------
No BCEX runtime code change is required. Existing 16KB Runtime 6.3 and 32KB Runtime 6.4.1 IPS patches remain current.
