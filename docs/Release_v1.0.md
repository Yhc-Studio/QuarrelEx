# Suggested GitHub Release text — QuarrelEx v1.0

## QuarrelEx v1.0

First formal public release of QuarrelEx, a Battle City / Battle City Ex editor for Windows and Web.

### Included
- Desktop editor 1.0 source project (.NET 8 / WinForms).
- Web editor 1.5.1 and standalone HTML build.
- A direct 16KB IPS, plus a 32KB preparation helper + IPS workflow, both based on the documented clean Battle City (J) ROM.
- QuarrelExConfig v3 spec and example.

### Important
No copyrighted ROM image is included. Verify the base ROM checksum before applying an IPS patch.

### Recommended release assets
- `QuarrelEx_Web_v1.5.1.zip`
- `QuarrelEx_Standalone.html`
- `QuarrelEx_BCEX_16KB_v1.0.ips`
- `QuarrelEx_BCEX_32KB_v1.0.ips` + `prepare_32k_base` helper scripts
- `QuarrelExConfig_v3_example.qexcfg.json`
- A Windows Desktop binary ZIP built from `desktop/QuarrelEx.sln` (build this on Windows/VS2022 before attaching).
