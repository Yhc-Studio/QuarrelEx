Battle City Ex v2 - Runtime 6.8 Final Rules v4
================================================

Runtime 6.8 is the current 32KB / 70-independent-map build used by QuarrelEx v1.1.4. QXR1 remains v4; Runtime 6.8 fixes automatic bonus-tank ordinal handling and removes the legacy item-clear side effect.

QXR1 v4 additions
------------------
- Armored One Hit is now spawn-time: normal E0 armored tanks stay E0 (white 1HP) when enabled.
- Flashing/item armored tanks remain E4 and keep original four-hit durability + item behavior.
- Stage 1~70 BaseExists table at CPU $BF78-$BFBD, default 01 for all stages.
- Normal stage HQ drawing and shovel-protected HQ drawing are routed through v4 wrappers. BaseExists=00 leaves the underlying stage map/collision cells untouched.
- Demo and Construction keep original HQ behavior.

Compatibility
-------------
- QXR1 v2/v3 data and all Runtime 6.5/6.6 features remain compatible.
- Config remains QuarrelExConfig v3; BaseExists is an optional per-stage field.

Runtime 6.8 bonus-tank fix
--------------------------
- QXR1 data layout remains v4.
- Automatic flashing tanks are selected by spawned-enemy ordinal #4/#11/#18, so EnemyTotal > 20 no longer shifts them into enemy #21+.
- The automatic flashing-tank spawn path no longer forcibly writes 00 to the active-item X byte, so a visible item is not deleted merely because the next automatic bonus tank appears.
